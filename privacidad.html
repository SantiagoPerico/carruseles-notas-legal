Política de privacidad

carruseles-notas es una herramienta personal de Santiago Perico, de uso exclusivo de su autor.

Qué datos usa

La herramienta accede a la cuenta de Google Drive de su autor para leer, crear y mover archivos dentro de carpetas específicas de esa misma cuenta (borradores de texto y videos).

Dónde se procesan

Todo el procesamiento ocurre en el computador personal del autor. La herramienta no tiene servidores propios y no guarda datos de Google en ningún otro lugar.

Con quién se comparten

Con nadie. Los datos no se venden, no se comparten con terceros y no se usan para publicidad.

Uso de datos de Google

El uso de la información recibida de las API de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions.
